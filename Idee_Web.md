Nach der Umsetzung von PLAN.md die erfolgt ist, soll nun eine Webapplikation mit Zugriff auf die Serielle Schnittstelle zum Flashen der Firmware und zur Konfiguration erstellt werden.

Flashen soll auf allen Entgeräten ermöglicht werden die die Serielle Schnittstelle bedienen können.

Das zu flashende Device soll automatisch erkannt werden und zur Auswahl gebracht werden.

Flashen und Konfigurieren sie zwei eigene Menüpunkte

Die Ablage der fertigen Firmware soll geregelt werden. Ein Automatischer Build ist im ersten schritt nicht vorgesehen.

Die Anwendung soll unter github Pages public bereit gestellt werden.

Notwendige Funktionen zu Prüfung der notwendigen Seriellen Schnittstellen sollen bereit gestellt werden.

Das Layout soll sich an dem Layout der Seite: https://hesspet.github.io/Zauberhaft/ orientieren, da es später von dieser Seite aus meist aufgerufen wird.

YAGNI Prinzip bewahren. Die Anwendung soll für einen unbedarften Anwender (Zauberer, Puppenspieler) bedienbar sein. 

Verständliche Führungstexte und Hilfetexte sind notwendig. Es soll keine weitere Dokumentation notwendig sein. Die Anwendung ist für Nutzer mit grundsätzlichen Wisssen um IT Bedienung

Ein eigener Menüpunkt Youtube soll bereit gestellt werden. Hier sollen dann einfache Anwendungsvideos aufgerufen werden können. Die Videos sollen auf der Webseite Embeddet sein.

Testvideos auf meinem Kanal zur testweisen Bereitstellung. Noch nicht die endgültigen Videos:

* https://www.youtube.com/watch?v=Bc23cLfiF6I (Titel Dummy1)
* https://www.youtube.com/shorts/OBm9twsoMng (Titel Dummy2)

Das Web soll Zweisprachig sein. Default Deutsch, zweite Sprache Englisch, Auswählbar über ein Menüpunkt.

Ein Weiterer Menüpunkt zu mehrere Texte zur Technischen integration bereit stellen. Die Texte sollen als Markdown mit Bildern bereit gestellt werden. Baue hierzu 2 Dummy Texte als Beispiel ein.

Stelle Rückfragen bei Widersprüchen und unklaren Punkten.

Erstelle eine Datei PLAN2.md in der die geplante Umsetzung beschrieben wird, so dass in einem neuen Kontext das Projekt umgesetzt werden kann.

Führe keine Schritte zur Implementation aus.
